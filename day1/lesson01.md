## 📖 강의 내용 (20분)

### 1. 파이썬이란?

#### 파이썬의 탄생
- **1991년** 네덜란드의 **귀도 반 로섬**(Guido van Rossum)이 개발
- 이름의 유래: 영국 코미디 쇼 **"몬티 파이썬의 날아다니는 서커스"**에서 따온 이름
- 뱀🐍이 아니라 코미디 쇼가 원래 유래!

#### 파이썬이 인기 있는 이유

| 장점 | 설명 |
|------|------|
| **쉬운 문법** | 영어와 유사해서 초보자도 배우기 쉬움 |
| **다양한 활용** | 웹, 데이터 분석, AI, 자동화, 게임 등 |
| **풍부한 라이브러리** | 이미 만들어진 도구가 엄청 많음 |
| **활발한 커뮤니티** | 전 세계 개발자들이 도움을 줌 |
| **높은 수요** | 취업 시장에서 가장 인기 있는 언어 |

#### 파이썬을 사용하는 곳 (실제 사례)
- 🎬 **넷플릭스**: 추천 알고리즘
- 📸 **인스타그램**: 서버 백엔드
- 🎵 **스포티파이**: 음악 추천
- 🚀 **NASA**: 과학 계산
- 🤖 **ChatGPT**: AI 개발
- 🎮 **게임**: 문명 IV의 게임 로직

> 💡 **비유**: 파이썬은 프로그래밍 세계의 "만능 스위스 아미 나이프"!

#### 다른 언어와의 비교
```
# Python — 같은 작업을 할 때 가장 짧고 읽기 쉬움
print("Hello, World!")

// Java — 같은 작업인데 코드가 훨씬 길다
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 2. 개발 환경 설정

### 3. 대화형 모드 vs 스크립트 모드

| 모드 | 사용법 | 특징 |
|------|--------|------|
| **대화형(Interactive)** | 터미널에서 `python` 입력 | 한 줄씩 즉시 실행, 테스트에 좋음 |
| **스크립트(Script)** | `.py` 파일 작성 후 실행 | 여러 줄 코드, 실제 프로그램 작성 |

```
# 대화형 모드 (>>>가 나타남)
>>> 1 + 1
2
>>> print("안녕!")
안녕!
>>> exit()  # 종료
```

```
# 스크립트 모드 (hello.py 파일 작성 후)
# 터미널에서: python hello.py
```

> 💡 **비유**: 
> - 대화형 모드 = 계산기 (바로바로 답을 확인)
> - 스크립트 모드 = 레시피 작성 (여러 단계를 한 번에 실행)

### [예제 1-3] 줄바꿈과 특수 문자

> `\n`, `\t` 같은 특수 문자(이스케이프 시퀀스)를 배워 봅시다.

```python
# \n — 줄바꿈 (new line)
print("첫 번째 줄\n두 번째 줄\n세 번째 줄")

# \t — 탭 (tab, 일정 간격 띄우기)
print("이름\t나이\t직업")
print("철수\t25\t학생")
print("영희\t30\t개발자")
print("민수\t28\t디자이너")

# \\ — 백슬래시 자체를 출력
print("파일 경로: C:\\Users\\Documents")

# \" 또는 \' — 따옴표 출력
print("그는 \"파이썬 최고!\"라고 말했다")
print('It\'s a beautiful day')
```

**실행 결과:**
```
첫 번째 줄
두 번째 줄
세 번째 줄
이름	나이	직업
철수	25	학생
영희	30	개발자
민수	28	디자이너
파일 경로: C:\Users\Documents
그는 "파이썬 최고!"라고 말했다
It's a beautiful day
```

| 이스케이프 문자 | 의미 |
|:---:|------|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 백슬래시(`\`) |
| `\"` | 큰따옴표 |
| `\'` | 작은따옴표 |

### [예제 1-4] print의 end와 sep 옵션

> print()의 숨겨진 기능! end와 sep로 출력 형태를 바꿔봅시다.

```python
# end: 출력 끝에 붙는 문자 변경 (기본값: 줄바꿈 \n)
print("Hello", end=" ")
print("World")         # Hello World (한 줄에 출력됨!)
print()                 # 빈 줄

# end 활용: 카운트다운
print("발사 카운트다운: ", end="")
print(5, end="...")
print(4, end="...")
print(3, end="...")
print(2, end="...")
print(1, end="...")
print("🚀 발사!")
print()

# sep: 여러 값 사이의 구분자 변경 (기본값: 공백 " ")
print("2024", "01", "15", sep="-")      # 2024-01-15
print("010", "1234", "5678", sep="-")   # 010-1234-5678
print("서울", "부산", "대구", sep=" → ")  # 서울 → 부산 → 대구
print("A", "B", "C", "D", sep="")       # ABCD (구분자 없음)
```

**실행 결과:**
```
Hello World

발사 카운트다운: 5...4...3...2...1...🚀 발사!

2024-01-15
010-1234-5678
서울 → 부산 → 대구
ABCD
```

> 🔑 **핵심**: 
> - `end` = print가 끝날 때 뭘 붙일지 (기본: 줄바꿈)
> - `sep` = 여러 값 사이에 뭘 넣을지 (기본: 공백)

### [예제 1-5] 간단한 사칙연산 — 계산기처럼 사용하기

> 파이썬을 거대한 계산기로 써 봅시다!

```python
# 더하기
print("3 + 5 =", 3 + 5)         # 8

# 빼기
print("10 - 3 =", 10 - 3)       # 7

# 곱하기
print("4 × 5 =", 4 * 5)         # 20

# 나누기 (항상 실수로 결과)
print("10 ÷ 3 =", 10 / 3)       # 3.3333...

# 몫 (소수점 버림)
print("10 ÷ 3의 몫 =", 10 // 3) # 3

# 나머지
print("10 ÷ 3의 나머지 =", 10 % 3)  # 1

# 거듭제곱 (제곱)
print("2의 10승 =", 2 ** 10)    # 1024
print("3의 4승 =", 3 ** 4)      # 81

# 복합 계산
print()
print("복합 계산 예시:")
print("(10 + 5) × 2 =", (10 + 5) * 2)     # 30
print("100 - 3 × 20 =", 100 - 3 * 20)     # 40 (곱셈이 먼저!)
print("(100 - 3) × 20 =", (100 - 3) * 20) # 1940
```

**실행 결과:**
```
3 + 5 = 8
10 - 3 = 7
4 × 5 = 20
10 ÷ 3 = 3.3333333333333335
10 ÷ 3의 몫 = 3
10 ÷ 3의 나머지 = 1
2의 10승 = 1024
3의 4승 = 81

복합 계산 예시:
(10 + 5) × 2 = 30
100 - 3 × 20 = 40
(100 - 3) × 20 = 1940
```

| 연산자 | 의미 | 예시 | 결과 |
|:---:|------|:---:|:---:|
| `+` | 더하기 | `3 + 5` | `8` |
| `-` | 빼기 | `10 - 3` | `7` |
| `*` | 곱하기 | `4 * 5` | `20` |
| `/` | 나누기 | `10 / 3` | `3.333...` |
| `//` | 몫 | `10 // 3` | `3` |
| `%` | 나머지 | `10 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

> 🔑 **핵심**: 수학과 같은 연산 순서! 괄호 → 거듭제곱 → 곱셈/나눗셈 → 덧셈/뺄셈

### [예제 1-7] 여러 줄 문자열과 문자열 연산

> 문자열(텍스트)도 연산이 된다는 사실! 놀랍죠?

```python
# 여러 줄 문자열 (삼중 따옴표)
poem = """
장미는 빨갛고,
제비꽃은 파랗다.
파이썬은 멋지고,
나도 그렇다!
"""
print(poem)

# 문자열 더하기 (+) = 문자열 연결
first_name = "김"
last_name = "파이"
full_name = first_name + last_name
print("이름:", full_name)        # 이름: 김파이

# 문자열 곱하기 (*) = 문자열 반복
line = "=" * 30
print(line)                      # ==============================
print("⭐" * 10)                # ⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
print("하하 " * 3)              # 하하 하하 하하 

# 문자열 길이 (len 함수)
greeting = "Hello, Python!"
print(f"'{greeting}'의 길이: {len(greeting)}자")  # 14자
```

**실행 결과:**
```

장미는 빨갛고,
제비꽃은 파랗다.
파이썬은 멋지고,
나도 그렇다!

이름: 김파이
==============================
⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
하하 하하 하하 
'Hello, Python!'의 길이: 14자
```
