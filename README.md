# 🐍 파이썬 프로그래밍 교안

> **교재**: 점프 투 파이썬 (메인) + 파이썬 코딩 도장 (보충 예제)  
> **대상**: 프로그래밍 초보자  
> **기간**: 5일 × 3차시 = 15차시 + 부록 1차시  
> **1차시**: 50분 (강의 20~25분 + 실습 25~30분)  
> **최종 목표**: Flask 기반 할 일 관리 웹 애플리케이션 제작

---

## 🚀 시작하기

1. Python 3.10+ 설치: https://python.org
2. VS Code 설치 (권장): https://code.visualstudio.com
3. 필수 패키지 설치: `pip install flask requests`

### 🎓 인터랙티브 교육용 웹앱 실행 (권장)

브라우저에서 전체 15차시 교안 열람, 브라우저 실시간 파이썬 코드 실행, 차시별 퀴즈를 모두 지원하는 학습 포털입니다:

```bash
python c:\Users\kotc2\antigravityF\Jpy\classroom\app.py
```
👉 브라우저 주소: **`http://127.0.0.1:8080`**

## 📝 강사 가이드

- 각 차시에 **6~8개 예제 + 1개 도전 과제**가 포함되어 있습니다
- `examples/` 폴더에 바로 실행 가능한 `.py` 파일이 있습니다
- 교육용 웹앱(`classroom/`)의 **'실습실(Live Runner)'** 탭에서 예제 코드를 즉시 불러와 학생들과 실시간으로 실행하고 변형해볼 수 있습니다
- 시간이 부족하면 뒷번호 예제와 도전 과제를 생략하세요
- 시간이 남으면 도전 과제를 변형하여 추가 실습을 진행하세요
